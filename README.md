# Postfire — 5v5-шутер внутри поста в X

3D-шутер от первого лица, который открывается прямо в карточке поста (X Player Card).
Все, кто открыл ссылку на мир, попадают в один матч: 10 человек играют 5v5, остальные стоят в очереди и смотрят.

## Что внутри

- **Матч**: 5v5, раунды на выбывание (115 с), до 7 побед. Две пушки: VX-7 (авто) и P-12 (пистолет), перезарядка, разброс, отдача, хедшоты.
- **Очередь**: максимум 10 игроков в матче. Лишние ждут в очереди (FIFO) и смотрят игру от третьего лица.
  Свободный слот отдаётся следующему в очереди в конце раунда. Игрок, который простаивает 40 с при непустой очереди, уходит в конец очереди.
  После матча проигравшая команда уступает места очереди («победители остаются»).
- **Боты** держат в мире минимум 4 бойца, поэтому одиночный игрок сразу попадает в бой. Боты уступают места живым игрокам.
- **Сервер решает попадания** с компенсацией задержки (откат позиций на ping/2 + 100 мс). Перемещения проверяются по скорости.
- **Графика**: PBR-материалы, освещение от HDRI-фото неба, тени, AO, bloom, SMAA, анимированные солдаты, следы от пуль.
  Режимы High и Fast переключаются на стартовом экране; на телефонах по умолчанию включён Fast.
- **Мобильные**: виртуальный стик, стрельба, прыжок, перезарядка; прицеливание свайпом по правой половине экрана.

## Запуск локально

```bash
npm install
npm run assets   # один раз: скачать фотоскан-текстуры (см. ниже)
npm start        # http://localhost:8080
```

Главная страница создаёт мир и даёт ссылку `/w/<id>`. Эту ссылку и нужно постить.

## Фотореалистичные текстуры (рекомендуется)

`npm run assets` скачивает с [Poly Haven](https://polyhaven.com) (CC0, можно использовать коммерчески):
песчаник для стен, плитку для пола, штукатурку для домов, доски для ящиков, металл и HDRI-небо.
Файлы попадают в `public/assets/tex/`, и игра подхватывает их автоматически.
`npm run assets -- --2k` скачивает текстуры в более высоком разрешении для десктопа.
Без этого шага игра работает на процедурных текстурах.

## Деплой

Нужен Node 18+ хостинг с поддержкой WebSocket: Railway, Fly.io, Render или любой VPS.
Статические хостинги (Cloudflare Pages, Vercel static) не подойдут.

При сборке (`npm run build`) сервер сам скачивает фото-текстуры с Poly Haven; если сайт недоступен, сборка не падает и игра работает на процедурных текстурах.

Переменные окружения:

| Переменная | Значение |
|---|---|
| `BASE_URL` | Публичный адрес **с https**, например `https://postfire.example.com`. Обязателен, иначе карточка X не заработает |
| `PORT` | Порт (по умолчанию 8080) |
| `X_HANDLE` | `@твой_ник` для подписи карточки (необязательно) |
| `BOT_FILL` | Сколько бойцов держать ботами (по умолчанию 4, `0` выключает ботов) |
| `MAX_SPECTATORS` | Лимит зрителей на мир (по умолчанию 150) |

Карточка X: страница `/w/<id>` отдаёт `twitter:card=player`, iframe `?embed=1` (1280×720) и превью `card.jpg`.
X кэширует карточки, поэтому после смены `card.jpg` проверяй её на новой ссылке мира.

## Ограничения и следующие шаги

- **Политика X**: Player Card формально предназначена для видео и аудио. Tweetcraft это сходит с рук, но X может отключить карточку.
- **Античит базовый**: сервер проверяет скорость, темп стрельбы, патроны и попадания, но не направление прицела. Аимбот возможен.
- **Масштаб**: один процесс Node держит десятки миров. При виральном запуске создавай много миров (по одному на пост или волну) или запускай несколько инстансов.
- **Модель солдата**: Mixamo (из примеров three.js), её можно использовать в играх. Для полностью своего стиля замени `public/assets/soldier.glb`.
- **Идеи**: режим с бомбой, экономика и закупка, вторая карта, гранаты, звуки шагов.
